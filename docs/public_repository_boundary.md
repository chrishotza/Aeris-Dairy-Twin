# Public repository boundary

AERIS combines original research code with references to external datasets, benchmark material and challenge-specific work.

## Public by default

The repository may contain original AERIS code, clean reconstructions, historical source scripts, documentation and synthetic fixtures created from scratch.

## Not copied from the corpus

The repository does not include:

- third-party raw videos or image datasets;
- third-party annotation corpora;
- external archives whose redistribution rights have not been established;
- the InoCrowd ownership/confidentiality agreement;
- challenge-room or partner communications as public source artifacts.

## Placeholder evidence

Files named as pilot placeholders in the corpus are not treated as executed field results.

## Historical scripts

Historical scripts are preserved for provenance, but their original filesystem assumptions, external data paths and challenge-specific workflows are not guarantees of production readiness.

## Before public experimental data release

Verify the license and redistribution terms for every external dataset, annotation set and derivative artifact. The clean public adapters are designed so that external research data can remain outside the repository.
